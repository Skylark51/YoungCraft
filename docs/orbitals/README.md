# Orbitals (2026-10-29)

상단 **Orbitals** 메뉴 또는 분석 도구 모음의 **Orbitals**를 선택합니다.

## CHK → FCHK

로컬 Gaussian 또는 계산 서버의 Gaussian을 사용합니다. 이 배포본은 함께 제공된 서버 프로필로 자동 연결합니다. **Gaussian 도구 경로**를 체크하고 `formchk.exe`, `cubegen.exe` 위치를 지정할 수 있습니다. PATH / g16root / g09root 및 C:/G16W, C:/G09W도 검색합니다. Gaussian 실행 파일은 이 배포본에 포함하지 않습니다. 실행에 필요한 Gaussian 환경변수는 앱 실행 환경에서 상속합니다.

**CHK / FCHK / cube 열기**로 `.chk`를 열면 백그라운드 파일 작업자가 `formchk input.chk converted.fchk`를 실행하고 결과를 검증합니다. 원본 CHK는 수정하지 않습니다. 변환된 파일은 앱 캐시에 보관하며 **변환된 FCHK 저장**으로 원하는 위치에 저장할 수 있습니다. 일반 열기/드래그도 CHK를 지원합니다. formchk 시작 실패·비정상 종료·120초 초과를 오류로 표시합니다.

## FMO

서버 자동 실행 모드에서는 CHK / FCHK를 열면 HOMO를 자동 생성합니다. **HOMO / LUMO**는 한 번 누르면 선택과 생성을 함께 수행합니다. 다른 궤도는 FMO 표에서 α/β MO를 선택하고 **선택 MO 생성**을 누릅니다. HOMO/LUMO는 현재 선택한 스핀 채널 기준입니다. FCHK에는 해당 MO 계수가 있어야 합니다. `cubegen 0 AMO=n input.fchk surface.cube npts h` 또는 BMO=n을 실행합니다.

40/80/120 격자 해상도, isovalue, 불투명도, 양/음 위상 표시와 색상을 조절합니다. 초기 MO isovalue는 0.02 a.u.입니다. MO와 MEP의 isovalue를 각각 기억하므로 다른 MO를 생성하거나 MO/MEP를 전환해도 지정한 값을 유지합니다. 카메라 회전·확대와 기존 이미지 복사/PNG 저장 기능을 사용합니다. 이는 표면 시각화 편집이며 파동함수 계수·점유수를 수정하는 양자화학 재계산 기능은 아닙니다.

## MEP

FCHK에서 **MEP 생성**을 누르면 선택한 SCF/MP2/CI/QCI 밀도의 전자밀도 cube와 정전기 퍼텐셜 cube를 순서대로 생성합니다. 해당 밀도가 FCHK에 존재해야 합니다. 전자밀도 등가면(초기 0.001 a.u.) 위의 각 꼭짓점에서 퍼텐셜을 삼선형 보간해 색으로 표시합니다. 기본 범위는 −0.05…+0.05 a.u., 빨강→흰색→파랑이며 범위와 양끝 색상을 변경할 수 있습니다. 양끝을 벗어난 값은 끝 색으로 제한됩니다. 범위 밖 보간 지점은 회색입니다.

색상 범례와 수치 범위는 이미지에도 포함됩니다. 생성 중 **계산 취소**가 가능합니다. 도구 실패 시 이전에 표시한 그림을 유지합니다. 여러 문서에서 계산해도 결과는 시작한 문서에 적용됩니다.

Gaussian 없이 이미 생성된 파일을 사용할 수도 있습니다. 전자밀도 `.cube` 또는 `.cub`를 연 뒤 **현재 density cube에 potential cube 매핑**으로 대응 퍼텐셜 cube를 선택합니다. 원자·좌표 일치와 격자 포함 범위를 확인합니다. 파일의 물리량은 cube 숫자만으로 판별할 수 없으므로 각각 올바른 물리량의 파일을 선택해야 합니다. 단일 MO cube는 지원하고, 다중 MO cube는 분리해서 가져와야 합니다.

## NBO / Wiberg

`.out` / `.log`에 실제 출력된 다음 표를 분석합니다.

- NPA: 자연전하, core / valence / Rydberg / total population
- NBO: 점유수와 orbital 설명
- E(2): donor / acceptor, 안정화 에너지(kcal/mol), 에너지 차이와 Fock 원소(a.u.)
- Wiberg: 원자쌍의 결합지수 (중복 대칭 원소 제외)

반복 계산·스핀 등 출력의 각 표 구간은 **Section** 번호로 구분합니다. 표 검색과 현재 보이는 행의 TSV 저장, 파싱 구간 원문 보기를 제공합니다. 지원 표가 없으면 빈 표/원문 안내가 나타나며 수치를 추정하지 않습니다. NBO 버전별 모든 출력 변형을 지원하는 것은 아닙니다.

## 검증

축이 비대칭인 MO cube, 단위·격자 직렬화, skew 격자 보간, 등가면, α/β 점유수, 반복 NBO와 분할 Wiberg 행렬, 도구 실패·취소·경로 공백/한글을 회귀 테스트합니다. 외부 프로세스 계약은 테스트용 실행 파일로 검증하며 실제 Gaussian 계산 검증과 구분합니다. 로컬 Gaussian 실행 파일은 발견되지 않아 실제 formchk/cubegen 계산은 검증하지 못했습니다. 실제 연구 FCHK(24원자, 672개 α/β 궤도) 읽기를 확인했습니다.

메뉴/툴팁/아이콘, MO·MEP 렌더링, isovalue 반영, 문서 전환 후 결과 귀속과 기존 분석 내비게이션을 GUI 테스트로 확인합니다. 검증용 그림은 합성 스칼라장으로 만든 렌더러 테스트이며 실제 분자의 계산 결과가 아닙니다.

명령 형식 참고: [Gaussian cubegen 매뉴얼](https://theochem.mercer.edu/chm295/g09ur/u_cubegen.htm).

## 생성되지 않을 때 (2026-10-30)

서버 자동 연결 모드에서는 CHK를 열면 FCHK 변환 후 HOMO를 자동 생성합니다. MEP는 화면 위쪽의 **MEP 생성**을 한 번 누르세요. 로컬 실행 또는 다른 MO를 선택할 때는 **선택 MO 생성**을 사용할 수 있습니다. Gaussian formchk / cubegen은 별도 설치된 실행 파일이 필요합니다.

도구가 없으면 큰 CHK를 복사하기 전에 실패 원인을 안내합니다. CHK 열기 실패는 대화상자에도 표시하고, FCHK를 읽었지만 cubegen이 없으면 Orbitals 상태 안내에 표시합니다. **Gaussian 도구 경로**에서 각각 실행 파일을 지정하세요. CHK 변환 실패 후에는 파일을 다시 열어야 합니다. Gaussian이 다른 PC/서버에 있다면 그 환경에서 FCHK와 MO cube 또는 density/potential cube를 생성해 가져올 수 있습니다.

## 계산 서버 실행 (2026-10-30)

앱 시작 시 함께 배포된 `youngcraft-server.json`의 기본 접속 설정을 읽고 서버 연결과 Gaussian 도구 사용 가능 여부를 자동 확인합니다. 화면의 **서버 연결됨** 상태를 확인할 수 있습니다. **서버 설정…**에서 사용자@호스트, SSH 포트, 필요 시 기존 SSH 설정/키 파일, 서버 Gaussian 폴더를 지정합니다. Windows OpenSSH와 기존 키 인증을 사용하며 비밀번호는 저장하지 않습니다. 처음 접속하는 서버는 일반 SSH에서 호스트 키를 확인하고 등록해야 합니다. 호스트 키 검사를 생략하지 않습니다.

설정 후 로컬 CHK를 열면 서버 formchk로 변환한 FCHK를 내려받아 MO 표를 채웁니다. MO를 선택하고 **선택 MO 생성**, 또는 **MEP 생성**을 누르면 서버 cubegen으로 계산하고 실제 cube를 내려받아 표시합니다. 계산은 백그라운드에서 진행하며 단계별 상태와 취소 버튼을 제공합니다. SSH 접속 실패와 변환/생성 오류를 표시합니다.

**서버 CHK 폴더**를 지정하면 같은 이름의 파일과 로컬 파일의 크기 및 SHA-256을 확인하고, 일치할 때 서버 사본을 사용해 업로드를 생략합니다. 일치하지 않으면 로컬 파일을 전송합니다. 서버 원본은 수정하지 않습니다. 각 작업은 별도 UUID 임시 폴더와 scratch를 사용하고 완료/실패/취소 시 해당 폴더만 정리합니다. 네트워크 단절로 정리를 못 하면 상태에 작업 폴더를 표시합니다. 내려받은 FCHK/cube는 로컬 앱 캐시에 남으며 cube 위치는 완료 안내의 툴팁에서 확인할 수 있습니다.

해상도 40/80/120은 cubegen의 npts 옵션입니다. 실제 격자의 각 축 길이는 분자 범위에 따라 달라질 수 있습니다. 생성 파일만으로 MO 계수·점유수를 다시 계산하지 않습니다.

## 자동 연결과 즉시 표시 (2026-10-30)

서버 프로필을 배포본에 포함하므로 별도로 서버 주소나 포트를 입력할 필요가 없습니다. 기존 SSH 키 인증과 호스트 키 검증을 사용합니다. **계산 서버 · 자동 연결**에는 연결 중/연결됨/실패 상태와 **자동 재연결** 버튼이 표시됩니다. 고급 설정을 바꾸지 않아도 CHK 열기 → 서버 변환 → 다운로드 → 기본 HOMO 생성 → 화면 표시가 이어집니다. HOMO/LUMO/MEP 버튼과 계산 진행·취소 안내는 패널 상단에 있습니다. MEP는 한 번 눌러 생성합니다.

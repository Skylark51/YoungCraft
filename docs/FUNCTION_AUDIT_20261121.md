# Youngcraft 전체 기능·접근 성능 점검 (2026-11-21)

기존 기능을 유지하면서 실행·파일 열기·계산·표시·내보내기 경로를 검사했다. 사용자 예제와 기존 미커밋 파일을 보존했다.

## 개선 사항

- **단일 EXE 실행**: Windows CNG SHA-256과 순차 읽기를 사용하고 최초 추출 직후의 중복 검사를 제거했다. 이후 실행에도 모든 배포 파일의 전체 SHA-256을 확인한다. 파일 크기·수정 시간만으로 검증을 생략하지 않는다.
- **대형 구조 결합 계산**: 전체 원자쌍 비교를 인접 공간 셀 검색으로 바꾸었다. 결합 판정, 결합 순서, 수소·금속·가시성 조건, 수동 결합을 유지한다. 작은 구조와 비정상/극단 좌표는 기존 방식으로 계산한다.
- **파일 전달**: 이미 열린 앱에 파일을 전달할 때 수신을 먼저 확인하고 문서 UI 생성을 예약해 호출 프로세스의 불필요한 대기를 줄였다.
- **백그라운드 문서 완료**: 현재 문서의 재생을 중단하지 않는다. MM 실행 중 다른 문서의 분석이 끝나면 현재 계산을 보존하고, 계산 종료 또는 문서 전환 뒤 결과를 적용한다.
- **MM 초기화 일시정지**: 일시정지 중 도착한 GFN-FF 전환 요청을 보관하고 재개 때 처리한다. 종료한 worker를 잘못된 응답으로 처리하지 않으며, 원자 고정 등 계산 조건을 보존한다. 중단하면 보류된 전환도 취소한다.
- **좁은 창**: 숨겨진 문서 페이지의 최소 폭 때문에 창이 강제로 커지는 현상을 고쳤다. 820×640에서 기존 패널 동작을 확인했다.
- **문양 변경**: 문양만 바꿀 때 전체 테마를 다시 적용하던 처리를 제거해 사용자 분자 배경색과 표시 스타일을 보존한다.
- **배포**: PowerShell 5에서도 네이티브 도구를 콘솔 없이 확실히 실행한다. CMake는 빌드 캐시에 기록된 경로를 사용한다. 바탕화면에는 단일 EXE를 게시하고, 대상 경로가 확인된 기존 Youngcraft 바로가기만 정리한다.

## 검증

| 범위 | 결과 |
| --- | --- |
| 실제 Windows/OpenGL GUI·상호작용 | 133 통과, 실패 0, 선택 검사 5 제외 |
| CTest 핵심 모듈 | 11/11 통과 |
| 독립 실행 EXE·패키징 | 12/12 통과 |
| 새 MM runtime 제약 검사 | 7/7 통과 |
| 이전 MM runtime 동일 제약 검사 | 7/7 통과, 출력된 목표 거리·각도·이면각 결과 일치 |
| 실제 Gaussian·ORCA·CIF 공개 자료 | 통과: 최적화, 진동, TD-DFT, scan, IRC, 결정 구조 |

GUI 범위에는 파일 열기·드롭, 문서/창 전환, 구조 편집과 실행 취소, 원자 선택·측정, 리간드·프로젝트, 주파수·Scan·IRC·TD-DFT/NTO, 오비탈, 테마·도움말, 투명 캡처·저장·애니메이션, MM과 실제 xTB 계산이 포함된다. 검사 실행본에도 MM/xTB runtime과 JPEG/GIF/ICO 플러그인을 배치했다.

결합 검색은 독립적인 기존 원자쌍 판정과 650원자 혼합 구조의 128개 조건 조합을 비교했다. 수동 결합·경계 거리·음수 좌표·비정상 cutoff도 확인했다. 패키징 검사는 동시 실행, 한글/공백 경로, 인수 전달, 설정 이관, 변조/누락/위험한 경로를 다룬다. 동일 크기로 파일을 변조하고 원래 수정 시간을 복원해도 SHA-256 검사에서 거부한다.

## 측정

- 같은 12,000원자 구조: 원자쌍 기준 약 **490ms → 공간 검색 6ms**. 실제 부하는 구조 밀도에 따라 달라진다.
- 같은 약 199MB payload/cache를 매번 전체 검증한 5회 측정 중앙값: **680.9ms → 488.4ms** (약 28% 감소). 백그라운드 빌드 중 측정한 단일 PC 결과이며 전체 GUI 표시 시간과는 구분한다.
- 최초 추출은 새 C드라이브 캐시에서 개선 런처 3.6초를 관찰했다. 디스크·보안 검사·OS 캐시에 따라 달라진다.

## 제외한 통합 검사와 환경 제약

GUI의 선택 검사 5개는 실제 PowerPoint 연동, 사용자 지정 메커니즘 프로젝트, 실제 원격 오비탈 결과, 실서버 자동 CHK/HOMO 생성, 별도 실제 scan 폴더다. 관련 로컬 모델·렌더링·파일 경로는 기본 검사로 확인했다.

이 PC의 Windows OpenSSH는 앱 외부에서도 ssh -V 및 ssh-keygen -?에 출력 없이 종료 코드 255를 반환했다. 비밀번호 전달용 private IPC는 통과했으며, 실제 OpenSSH 호출과 실서버 로그인은 검증되지 않았다. 운영체제 SSH 구성이나 사용자 인증정보는 변경하지 않았다.

## 빌드·배포

- MSVC Release / Qt 6.8.3 / Windows OpenGL.
- tools/build_mm_runtime.ps1로 RDKit **2026.03.6** / PyInstaller **6.22.3** MM runtime을 새로 생성했다. 기존 RDKit 버전을 유지했다.
- tools/package_portable.ps1 → tools/install_portable.ps1 → tools/create_desktop_patch.ps1 순서로 배포한다.
- 설치 대상: %LOCALAPPDATA%\Programs\Youngcraft Portable. 바탕화면 실행 파일: YoungCraft.exe.
- ZIP·단일 EXE·이전 배포 백업·상세 로그는 작업 폴더와 .build/function-audit-20261121에 보관한다.

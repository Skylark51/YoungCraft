# IRC · TS · IRC 맞춤 캡처

기존 이미지 복사, TS 애니메이션 복사, 그림/애니메이션 저장 기능을 유지하고 별도 맞춤 캡처 창을 추가했습니다.

## 사용

1. `이름-freq-ts-freq.out`을 연 뒤 상단 **맞춤 캡처** 또는 **편집 > 맞춤 캡처**, `Ctrl+Alt+I`로 캡처 창을 엽니다. 파일을 열 때는 자동으로 나타나지 않습니다.
2. 같은 폴더에서 `이름-freq-ts-freq-ircfwd-opt-freq.out`, `이름-freq-ts-freq-ircrev-opt-freq.out`을 백그라운드로 읽습니다. 양쪽 파일은 최종 구조, 가운데는 첫 허수 진동 모드를 사용합니다. 진폭·주기는 창을 열 당시 Freq 설정을 따릅니다.
3. 가운데 TS를 회전·확대·이동하면 양쪽도 같은 카메라를 따릅니다. 원래 TS 뷰에서 카메라를 바꾸어도 반영됩니다. IRC 구조는 원자 순서와 원소를 검증하고 TS에 강체 회전 정렬합니다. 주로 비수소 원자를 사용하며 비수소 원자가 3개 미만이면 전체 원자를 사용합니다. 반사·원자 순서 변경은 하지 않습니다.
4. **IRC 좌우 교환**으로 순서를 바꿉니다.
5. Word는 각 5 cm, PowerPoint는 각 10 cm가 기본입니다. 두 프리셋의 사용자 너비는 따로 기억합니다. 세 그림은 같은 너비·높이의 투명 캔버스를 사용합니다. 개별 구조의 종횡비는 유지하므로 구조 모양에 따라 투명한 여백이 남을 수 있습니다. TS는 전체 진동 범위로 자르고 기존 2% 여유를 유지합니다.
6. **한 줄 복사**는 투명 PNG·GIF·PNG 세 이미지 데이터를 직접 담은 HTML과, 가운데만 움직이는 합성 투명 GIF를 클립보드에 제공합니다. 대상 앱이 선택한 붙여넣기 형식에 따라 세 이미지 또는 합성 GIF가 사용됩니다. 로컬 파일 링크 대신 이미지 데이터를 넣어 Word의 빈 그림 틀 문제를 피합니다.
7. **왼쪽 복사 / TS GIF 복사 / 오른쪽 복사**로 각각 붙여넣거나, **PNG·GIF 3개 저장**으로 새 폴더에 저장할 수 있습니다. PNG에 실제 크기 정보를 기록하며 TS GIF 크기는 HTML에서 지정합니다. 저장 폴더의 `paste.html`에도 실제 크기가 들어갑니다.

PowerPoint는 GIF의 HTML 크기를 무시하므로 PPT 프리셋에서는 GIF 자체를 96 dpi 기준 픽셀 수(10 cm는 약 378 px)로 맞춥니다. 양쪽 PNG는 1000 px 고해상도를 유지합니다. 두 프리셋 모두 높이와 너비를 맞추며 GIF 픽셀 반올림에 따른 0.05 cm 미만의 차이가 생길 수 있습니다.

Office의 붙여넣기 형식/보기 모드에 따라 GIF를 정지 그림으로 표시할 수 있습니다. 원본 GIF는 다중 프레임으로 유지하며 PNG 두 장과 TS GIF를 따로 저장할 수 있습니다. 클립보드의 이미지 데이터는 자체 포함되며 GIF 보조 파일은 앱 종료 후 붙여넣기도 가능하도록 캐시에 유지합니다.

관련 IRC 파일이 없거나 원자 수·원소 순서가 다르면 오류 경로를 표시하고 복사 버튼을 비활성화합니다. 원본 문서의 좌표·결합·재생 상태는 수정하지 않습니다.

## 캡처할 때 수소 표시

- **수소 제거 (C–H)**: 기존 메인 화면 기능과 같이 TS에서 탄소에 결합된 수소를 숨기고 O–H·N–H 등은 유지합니다. C–H 여부는 TS의 원래 결합으로 판정하므로 IRC에서 결합이 끊겨도 같은 수소 번호를 숨깁니다.
- **선택 수소 제외 숨기기**: 남길 H를 구조에서 클릭하거나 **남길 수소** 번호 목록에서 체크한 뒤 누릅니다. 체크한 수소만 남기고 나머지 모든 수소를 숨깁니다. C–H activation에 해당하는 수소를 남길 때 사용할 수 있습니다. 여러 수소를 선택할 수 있으며, 숨긴 뒤에도 번호 목록을 체크/해제해 즉시 바꿀 수 있습니다.
- **수소 복원**: 세 구조의 모든 수소를 다시 표시합니다. 남길 수소의 체크는 유지하므로 다시 선택 수소 제외 숨기기를 적용할 수 있습니다.

수소 표시 상태는 TS·양쪽 IRC의 같은 원자 번호에 적용되며 미리보기, 한 줄/개별 복사, PNG/GIF 저장에도 반영됩니다. 원자·결합을 삭제하지 않으며 원래 문서의 표시 상태·좌표와 캡처 카메라를 유지합니다. 선택 표시 테두리는 출력에 포함하지 않습니다.

수소 제어 GUI 검증은 `hydrogen-test.txt`에 기록했습니다. 실제 구조 클릭 선택, 체크 목록으로 숨긴 수소 복원, C–H/O–H 구분, 세 구조와 좌우 교환에 반영, 렌더링 결과 변경, 진동 재생 유지, 원본 구조 보존과 기존 맞춤 캡처 워크플로를 통과했습니다. 실행 파일 갱신 전 버전은 `Youngcraft-before-capture-hydrogens-20261025.exe`로 보관했습니다.

## 검증

- 수동 실행 변경: 파일 열기 후 캡처 창이 자동으로 열리지 않으며 상단 맞춤 캡처를 누르면 열리는 것을 Windows/OpenGL 워크플로로 확인했습니다. 기존 복사·수소 제어도 통과했습니다(`manual-open-test.txt`, 실패·건너뛰기 없음). Release 빌드 후 루트와 `dist/Youngcraft.exe`를 갱신했고 직전 실행 파일은 각각 `Youngcraft-before-manual-capture-20261025.exe`로 보관했습니다.
- Release 빌드 완료. 루트와 `dist/Youngcraft.exe`를 갱신했으며 이전 버전은 각각 `Youngcraft-before-reaction-capture-20261025.exe`로 보관했습니다.
- 모델 테스트 20개 통과: 파일명 규칙·한글 경로, 강체 회전 정렬, 원소 순서 불일치 거부, 투명 캔버스와 실제 크기 정보, 기존 GIF 인코딩·애니메이션 크롭을 포함합니다.
- Windows/OpenGL GUI 테스트 9개 통과(최초 구현 기준): 미리보기, 좌우 교환, 카메라 공유, 세 그림/개별 복사, 원본 좌표 보존, 관련 파일 누락, 기존 TS GIF 복사 4가지 시나리오와 투명 이미지 복사, 파일 열기를 확인했습니다.
- 설치된 Word에 실제 붙여넣기: 개별 그림 3개, 너비 각각 5.002 cm, 동일 높이. Word 문서 내부에서 추출한 TS GIF의 다중 프레임과 투명 알파를 확인했습니다.
- 설치된 PowerPoint에 실제 붙여넣기: 개별 그림 3개, 너비 10 / 10.001 / 10 cm, 높이 차이 0.005 cm 이내. 저장한 PPTX 내부에서 추출한 TS GIF의 다중 프레임과 투명 알파를 확인했습니다.
- 결과: `model-test.txt`, `workflow-test.txt`, `word-probe.json`, `ppt-probe.json`, `preview.png`, `row.gif`.

Office 붙여넣기 검증 스크립트는 `tests/smoke/paste_reaction_office.ps1`입니다. `YOUNGCRAFT_REACTION_OFFICE_PROBE`에 스크립트 경로와 `YOUNGCRAFT_REACTION_CAPTURE_DIR`에 결과 폴더를 지정해 GUI 워크플로 테스트에서 선택적으로 실행합니다. 이 검증은 사용 중인 프레젠테이션에 영향을 주지 않도록 PowerPoint가 열려 있으면 중단합니다. HTML 클립보드는 Microsoft의 [CF_HTML 형식](https://learn.microsoft.com/en-us/windows/win32/dataxchg/html-clipboard-format)을 사용합니다.

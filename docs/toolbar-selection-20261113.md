# 상단 도구 정리와 선택 모드 (2026-11-13)

반데르발스 구 표시를 원소별 실제 반지름의 공간 채움 렌더링에 연결했다. 색상·그림자·반투명 렌더링에서 결합을 숨기며 분자 데이터는 보존한다. 켤 때 구조를 화면에 맞추고 끄면 기존 표시 스타일로 돌아간다. 체크 상태는 문서 전환과 스타일 변경에 맞춘다.

안티앨리어싱 없이 이미지 복사 항목과 중복 구조 정리 항목을 제거했다. 오비탈 도구·환경설정은 메인 아이콘으로, 맞춤 캡처·탭 비교·메커니즘·TS 애니메이션은 내보내기 아이콘으로 모았다. 중복 원문 보기 사이드바 버튼을 제거했으며, 분석 데이터에 따른 문맥 탭과 표준 파일 메뉴는 유지했다. 기존 캡처 단축키도 유지했다. 도움말은 도움말 메뉴로 통합했다.

분자량 계산은 현재 화면의 전체 구조를 기준으로 화학식과 몰 질량(g/mol)을 보여 주고 확인으로 닫는 창을 연다. 숨긴 원자도 포함하며 더미 원자는 화학식에서 제외한다. 화학식은 탄소가 있으면 C/H/나머지 원소 순, 없으면 원소 기호 알파벳 순이다. 기존 원자량 표에 없던 표준 원자량은 [CIAAW 2024 abridged standard atomic weights](https://www.ciaaw.org/abridged-atomic-weights.htm)로 보완했다. 표준 원자량이 없는 원소는 불완전한 합계를 표시하지 않는다.

그리기 공백 우클릭은 그리기 도구·연속 사슬·삽입 대기를 해제하고 선택 모드로 전환한다. 다음 왼쪽 클릭은 원자를 추가하지 않고 선택한다. 원소 버튼으로 그리기를 재개할 수 있으며 우클릭 드래그 회전은 유지한다. 등각 보기는 (1,1,1) 방향의 직교 투영으로 세 축의 화면상 길이가 같도록 구현했다.

Windows Qt 6.8.3/MSVC 네이티브 GUI 검사: 새 동작 3개 및 기존 상단 패널·선택·클립보드·구조 텍스트·편집 트랜잭션 5개 통과(초기화/정리 포함 10 passed). 반데르발스 반지름·화면 안 배치·문서별 체크 상태·기존 스타일 복원·3축 투영 길이·화학식·누락 원자량·확인 버튼·선택과 회전 동작을 확인했다. 반데르발스 화면과 분자량 창 PNG를 확인했다.

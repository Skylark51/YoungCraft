# UI polish and TD-DFT publication output

- Theme 대신 손글씨 느낌의 소문자 `palette`를 사용합니다.
- 맞춤 캡처 아이콘은 정렬된 세 프레임과 조절 슬라이더를 결합합니다.
- Youngcraft 정보는 `Made by Youngseob Lee, Since 2026, only for JBNU and BIOCC`만 표시합니다.
- 표시 기능의 수소 제거는 수소 숨기기, 초기화는 수소 숨기기 초기화로 변경합니다. 실제 원자를 삭제하는 구조 편집 기능은 제거라는 명칭을 유지합니다.
- TD-DFT 곡선은 짙은 청색, 개별 전이는 가는 회색 막대로 구분합니다. 0 기준선과 적절한 여백, Arial 축 글꼴, 영문 물리량 표기를 사용합니다.
- 파장 구간은 실제 전이와 선폭을 기준으로 정하고, 최소 0.25 nm 간격으로 샘플링합니다(큰 구간은 약 4000점으로 제한). 가우스/로렌츠 선폭 확장 계산식은 유지합니다. 폭의 의미는 툴팁으로 설명합니다.
- 정규화 시 곡선과 막대 각각의 최대값을 1로 맞추는 기존 방식을 유지하며 툴팁에 명시합니다. 정규화 해제 시 축은 `Intensity (a.u.)`입니다.
- 출판용 저장은 단일/이중 칼럼 판형, 물리 크기, PNG 300/600/1200 dpi, 벡터 PDF를 제공합니다. 고해상도 복사는 단일 칼럼 600 dpi를 사용합니다.

`spectrum-600dpi.png`, `spectrum.pdf`, `tddft-workspace.png`는 테스트용 합성 전이 4개를 사용한 렌더링 예시입니다. 실제 실험 데이터가 아닙니다. 검사 로그는 `test-results.txt`에 기록합니다.

# 오비탈 관리 / 재사용

오비탈 패널의 **오비탈 확인…** 버튼은 비모달 관리창을 연다. 관리창은 소유 창이 있는 모니터의 작업 영역 내에 배치되며, 높이가 작은 화면에서는 스크롤한다. MO 표를 두 번 클릭하거나 HOMO/LUMO/생성 버튼으로 선택한다.

- `GaussianTools`는 cube와 potential을 256 MiB LRU 메모리 캐시에 보관한다. 키에는 파일 경로·크기·수정 시각, MO 번호·스핀, 해상도, 밀도 및 계산 환경을 포함한다.
- 디스크 저장소는 Qt `CacheLocation/orbital-library-v1`이다. 파일 내용 SHA-256와 계산 조건으로 주소를 정하고 cube 파일과 `info.json`을 원자적으로 저장한다. 새 프로세스에서도 저장된 cube를 읽으며, 손상되거나 불완전한 결과는 다시 생성한다. 디스크는 2 GiB를 기준으로 오래된 항목을 정리하며 현재 생성 항목은 보존한다.
- 파일 해싱·복사·도구 실행·cube 해석·저장은 작업 스레드에서 실행한다. 취소는 비동기로 처리하며 취소된 결과는 화면에 반영하지 않는다.
- 각 `MoleculeView`는 grid와 isovalue별 양/음 등가면을 256 MiB LRU 캐시에 저장한다. 동일 조건으로 돌아오면 등가면을 다시 계산하지 않는다. 한 뷰에서는 한 번에 하나의 등가면 작업만 실행하며 설정이 빠르게 바뀌면 최신 조건으로 수렴한다. 색·투명도·표현 방식 변경에는 cube나 등가면을 재생성하지 않는다.

최초 생성과 메모리 캐시에서 제거된 조건의 등가면 계산에는 시간이 필요하지만 UI는 계속 응답한다. 디스크 캐시는 임시 데이터이므로 OS가 지울 수 있다.

# 맞춤 캡처 경계 정렬과 별도 창 테마

IRC·TS 캡처는 제목 행과 3D 미리보기 행을 공통 그리드로 배치합니다. 제목 줄 수가 달라도 위·아래 경계가 일치하고 열 너비는 같습니다. 제목이 길어도 창의 최소 너비를 밀어내지 않도록 제목의 가로 크기 정책을 설정했습니다. TS를 숨기면 남은 두 뷰가 빈 열 없이 공간을 나눕니다. 다중 캡처도 각 묶음의 제목·미리보기 행을 공유합니다.

별도 창의 테마 전달은 `QWidget::isAncestorOf`가 창 경계를 넘지 않는 점 때문에 최초 Show 이벤트에서 누락됐습니다. 부모 위젯 연결을 직접 확인하도록 바꿔, 맞춤 캡처·다중 캡처·스타일 설정·계산 창 및 중첩 대화상자에 처음부터 바깥 창의 패턴과 색상을 적용합니다. 다중 캡처의 스크롤 영역 안쪽도 같은 창 좌표를 기준으로 문양을 그립니다. 투명 PNG/GIF 출력에는 UI 문양을 넣지 않습니다.

`dialogThemeSynchronization`에서 최초 표시, 여섯 색상, 긴 파일명, 너비·높이·상하 경계, 창 크기 변경, TS 숨김을 검사합니다. 기존 다중 캡처와 IRC·TS 캡처 테스트도 실행합니다. `workflow-test.txt`는 Windows 기본 125% 배율의 기능 테스트, `pattern-test.txt`는 100% 배율의 픽셀 비교 결과입니다. 기존 픽셀 비교 테스트는 1배 래스터 기준이므로 125% 배율에서는 안티앨리어싱 경계의 색 차이로 실패합니다.

실행 중이던 기존 Youngcraft 창은 종료하지 않았습니다. 해당 실행 파일은 `Youngcraft-running-before-capture-alignment-20261101.exe`로 보존했고, 새 실행 파일을 원래 위치에 빌드했습니다. 모든 기존 창을 종료한 뒤 다시 실행하면 수정본이 적용됩니다.

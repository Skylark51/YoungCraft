# 공통 아이콘과 버튼 기준 — 2026-11-23

Agent D 범위: `src/ui/SidebarButton.h`, 새 `src/ui/UiIcons.h`. 기존 11월 툴바 통합·선택 모드·오비탈 반응형 배치는 유지한다. 각 모듈 담당자가 호출부의 실제 기능을 확인한 뒤 의미 기반 아이콘을 선택한다. 번역 문자열·objectName·기존 QStyle 아이콘을 이용한 전역 자동 치환은 하지 않는다.

## API와 적용

두 헤더 모두 header-only이며 CMake나 리소스 등록이 필요 없다. `SidebarButton.h`가 `UiIcons.h`를 포함한다.

```cpp
#include "ui/SidebarButton.h"

// 기존 텍스트가 해당 동작을 설명하는 독립 아이콘 버튼.
auto *graph = new QPushButton(QStringLiteral("Scan 그래프"), parent);
makeSidebarIconButton(graph, UiIcon::Scan);

// 텍스트·자연 크기·메뉴 화살표를 유지하는 버튼.
setSidebarButtonIcon(exportButton, UiIcon::Export, QStringLiteral("내보내기"));

// QAction, 탭 등에도 적용. context는 해당 창의 팔레트를 따라가게 한다.
action->setIcon(uiIcon(UiIcon::Library, owner));

// 체크 상태와 사용 가능한 다음 동작을 함께 갱신.
setSidebarButtonIcon(show, visible ? UiIcon::Hide : UiIcon::Show,
    visible ? QStringLiteral("측정값 숨기기") : QStringLiteral("측정값 표시"));
```

`makeSidebarIconButton()`은 32×32 논리 픽셀의 독립 버튼용이다. 분할 버튼(열기·내보내기·라이브러리), 메뉴 화살표가 필요한 버튼, 명시적으로 텍스트를 보여 주는 버튼에는 사용하지 않는다. 이 경우 `setSidebarButtonIcon()` 또는 `setIcon(uiIcon(...))`만 사용한다. 기존 QStyle·QIcon 오버로드와 `sidebarLockIcon()`, `sidebarSaveIcon()`, `sidebarCopyIcon()`은 유지한다.

## 크기·표현·접근성

- 독립 아이콘 버튼은 기존 32px, 아이콘은 18px을 유지해 좁은 패널의 세로 높이가 늘지 않는다. 모호한 기능은 호출부에서 짧은 텍스트와 아이콘을 함께 사용한다.
- 아이콘은 24단위 도형·1.6단위 둥근 획으로 그린다. 고정 색·bitmap 대신 `QIconEngine`이 요청된 DPI로 그리며 일반·비활성·선택/체크 상태의 팔레트 색을 사용한다.
- `uiIcon(icon, widget)`은 `QPointer`로 위젯을 참조하므로 창의 테마 변경을 반영하고 위젯 소멸 뒤에는 앱 팔레트로 돌아간다. 창의 색을 따를 때 context를 전달한다.
- 기존 버튼의 명시적 접근성 이름·툴팁·단축키를 보존한다. 텍스트에서 이름을 만들 때 Qt mnemonic `&`를 제거하고 `&&`는 실제 `&`로 유지한다. 텍스트를 지우기 전에 mnemonic 단축키를 보관해 다시 설정한다.
- 별도 툴팁이 없을 때만 기능명과 기존 단축키를 조합한다. 상태 변경용 `setSidebarButtonIcon()`은 호출자가 전달한 새 기능명으로 접근성 이름과 툴팁을 갱신한다.
- `CenteredIconTabs`, 기존 SVG 시스템, 저장된 설정·단축키·과학 데이터는 변경하지 않는다.

## 검증 및 통합 시 확인

- 로컬 실행: 앱·위젯·GUI를 시작하지 않았다. 지정 worktree 안의 무시되는 `.build/icon-header-check/`에 컴파일 probe만 생성했다.
- MSVC 19.44 / Qt 6.8.3 / C++17 `/permissive- /Zc:__cplusplus /W4 /WX /Zs`: 성공. 두 버튼 종류, 3개 아이콘 입력 형식, 기존 호환 함수, 고정 크기 상수, QAction용 QIcon 생성 API를 컴파일했다.
- Qt 6.8.3의 `scaledPixmap()`이 논리 픽셀 크기를 받는 점을 [Qt 원문 소스](https://github.com/qt/qtbase/blob/v6.8.3/src/gui/image/qiconengine.cpp)와 대조했다. 실제 bitmap은 논리 크기×DPR로 할당하고 DPR을 설정한다.
- `git diff --check`: 통과. 전체 앱 빌드·GUI 회귀·배포는 부모 에이전트가 통합한 후 수행한다.
- E/부모의 GitHub Windows GUI 확인 항목: 100/125/150/200% DPI의 18px 아이콘 선명도·클리핑, 밝은/어두운 팔레트·테마 전환·비활성/체크 대비, 좁은 패널 높이, 분할 버튼 주 동작과 화살표, 명시적 접근성 이름/툴팁 보존, `&Save` mnemonic 및 Ctrl+S 보존, 두 번 아이콘 변환해도 접근성 이름 유지.
- 아이콘 변경만으로 유효 클릭 수 감소를 주장하지 않는다. 작업 경로·클릭 수·전후 화면 측정은 A/B/C 통합 후 E가 보고한다.

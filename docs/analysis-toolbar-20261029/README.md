# 분석 도구 모음 아이콘

분석 패널 표시, Opt, Freq, Scan, IRC, TD-DFT, Atom Properties, Orbitals, XYZ, 원자 번호를 기존 주 도구 모음과 같은 26px 아이콘으로 표시합니다. 순서와 클릭 동작은 유지합니다.

각 버튼에 기능을 설명하는 한국어 툴팁과 상태 표시줄 설명을 제공합니다. XYZ는 아이콘 내부에 XYZ 글자를 표시합니다. 선택된 버튼에는 흰색 아이콘을 사용합니다.

Release 빌드와 Windows/OpenGL GUI 검사: `topPanelToolbarFollowsDocuments`, `scanVisibilityAndSquareViewport`, `pastedXYZWorkflow`. 결과는 `test-results.txt`, 미리보기는 `preview.png`에 기록합니다.

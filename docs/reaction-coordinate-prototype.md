# 반응 좌표 애니메이션 프로토타입

`편집 → 전체 메커니즘 애니메이션…`에서 기존처럼 반응 경로 파일이나 열린 탭을 가져옵니다.

1. **반응 좌표 · 2D / 에너지 삽입…**을 누릅니다.
2. 필요한 단계에 **2D 그림 또는 상대 에너지 중 하나만** 입력해도 됩니다. 둘 다 입력하면 함께 움직입니다. 에너지 단위는 **kcal/mol**, 좌표는 단계 순서대로 증가해야 합니다. 에너지는 사용자가 선택한 공통 기준값을 사용합니다.
3. 단계를 선택해 **2D 그림 삽입…** 또는 **그림 붙여넣기**로 구조 그림을 넣습니다. PNG, JPEG, BMP, WebP, SVG를 지원합니다. SVG 읽기는 설치된 Qt 이미지 플러그인에 따릅니다. 그림은 PNG로 프로젝트 안에 저장되므로 원본 파일을 옮겨도 유지됩니다.
4. 구간 모양에서 **곡선 / 평평한 준위 / 직선**을 선택하고, 필요하면 **파선**을 켭니다. 구간 설정은 이전 단계에서 해당 단계로 가는 선에 적용됩니다. 평평한 준위는 양 끝에 수평 구간을 두고 가운데에서 연결합니다.
5. 도착 단계 그림에서 효과를 선택하고 두 점을 클릭합니다. 결합 형성은 녹색, 분해는 주황색으로 강조하고, 전자 밀도나 오비탈은 지정한 시작점에서 끝점으로 이동합니다. 여러 효과를 추가하거나 마지막 효과를 취소할 수 있습니다. 오른쪽 클릭은 미완료 점 지정을 취소합니다.
6. **반응 좌표 강조 · 2D / 에너지 동기화 사용**을 선택해 적용합니다. 반응 단계가 2개 이상이고, **그림 또는 유효한 에너지 중 하나라도 입력**되어 있으면 **2D · 에너지 동기화** 버튼이 활성화됩니다. 그림만 있으면 그림과 좌표 진행을, 에너지만 있으면 에너지 그래프를 표시합니다. 일부 단계만 입력해도 사용할 수 있으며, 미입력 에너지를 0으로 간주하거나 빈 구간의 에너지 곡선을 만들지 않습니다. 충돌 모션은 양 끝 에너지가 입력된 구간에만 적용됩니다. 좌표는 단계 순서대로 증가해야 합니다.
7. 동기화를 켜거나 **재생 화면 새 창…**을 누르면 반응 좌표 재생 화면이 **별도 창**으로 열립니다. 편집 창의 3D 화면은 위아래로 나누거나 축소하지 않습니다. 재생 창은 크기 조절·최대화·**전체 화면(F11)**이 가능하며, 자체 **재생 / 일시정지 / 처음 / 타임라인 / 반복** 조작이 편집 창과 동기화됩니다. 재생 창을 닫으면 일시정지하고, 다시 열면 그 위치에서 이어서 사용할 수 있습니다.
8. 2D 그림의 이동·전환, 그래프 위 추적점, 좌측 상단 Energetics 숫자와 에너지 게이지, 3D 구조가 같은 시각을 따릅니다. 높은 오르막 구간은 설정한 장벽 기준에서 잠시 부딪혀 되돌아간 후 진행합니다. 이는 에너지 부족 판정이나 반응 속도 계산이 아니라 설명용 모션입니다.

동기화 설정과 그림·효과는 기존 `.ycmechanism` 프로젝트에 함께 저장됩니다. 그림이 없는 기존 프로젝트는 종전대로 동작합니다. GIF / PNG 시퀀스 / MP4에도 동기화된 그래프와 2D 효과를 포함합니다. MP4에는 기존처럼 ffmpeg가 필요합니다.

그림 간 전환은 이동과 교차 페이드입니다. 그림에서 원자나 결합을 자동 인식하거나 원자별 2D 좌표를 계산하지 않습니다. 전자 밀도·오비탈은 사용자가 지정한 모식도이며 양자화학 계산 결과를 나타내지 않습니다.

## 수소 제거

**구조 만들기** 메뉴에서 다음 명령을 사용합니다.

- **탄소에 붙은 수소 제거**: 현재 결합 정보에서 C에 연결된 H만 실제로 제거합니다. O–H / N–H 및 탄소에 연결되지 않은 H는 유지합니다.
- **모든 수소 제거**: 구조의 모든 H를 실제로 제거합니다.
- **선택한 수소만 남기기**: Shift/Ctrl로 남길 H를 선택한 뒤 실행합니다. 선택한 중원자는 제거 대상에 영향을 주지 않습니다. H를 하나도 선택하지 않으면 구조를 유지하고 안내합니다.

제거 직후 자동 수소 보정으로 H를 다시 생성하지 않습니다. **Ctrl+Z / Ctrl+Y**로 취소·재실행할 수 있습니다. 계산 파일을 편집하면 기존 편집 방식에 따라 새 편집 탭을 만듭니다. 이 명령은 보기 메뉴의 수소 숨기기와 별도로 실제 원자·결합을 삭제합니다.

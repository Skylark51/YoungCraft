# 전체 메커니즘 애니메이션

상단 오른쪽 **메커니즘 영상** 또는 **편집 > 전체 메커니즘 애니메이션…**에서 엽니다. 기존 원자 강조 메뉴는 상단 오른쪽 **숨김·반투명**으로 이동했습니다.

## 만드는 순서

1. **파일 추가…**로 반응물, TS, 중간체, 생성물의 Gaussian/ORCA/XYZ 등 구조 파일을 넣습니다. 또는 **열린 탭 가져오기**로 열린 창·탭의 표시 구조를 가져옵니다. 원본 파일과 원본 탭은 바뀌지 않습니다.
2. 표의 ↑/↓로 반응 순서를 맞추고 단계 이름을 짧게 바꿉니다. **구간(초)**은 앞 단계에서 해당 단계까지의 이동 시간입니다. 첫 단계가 단일 구조이면 시간 0의 시작 구조이며, 첫 단계에 경로 프레임이 여러 개 있으면 그 프레임들의 재생 시간으로 사용합니다.
3. **추가할 파일의 IRC·다중 XYZ 경로 사용**을 켜면 IRC point / GSM node / multi-XYZ 프레임을 사용합니다. 일반 최적화·진동 계산 파일은 마지막 구조를 사용하며 최적화 반복을 반응 경로로 취급하지 않습니다. 경로가 거꾸로이면 해당 단계의 **역방향**을 체크합니다. 파일 선택 창의 정렬 순서는 반응 순서를 보장하지 않으므로 표에서 확인하세요.
4. **공통 원자로 단계 간 회전·위치 정렬**로 파일마다 달라지는 전체 회전을 제거합니다. **변하지 않는 결합 길이 유지**는 보간 중 공통 결합이 찌그러지는 것을 줄입니다. 생성·해제·차수 변화가 있는 결합은 페이드로 연결합니다.
5. 재생·일시정지, 슬라이더로 검토합니다. 우클릭으로 회전, 휠로 확대합니다. 카메라는 매 프레임 다시 맞추지 않습니다. **전체 경로 맞춤**으로 모든 단계와 이탈 조각까지 한 번에 맞춥니다. 기본 재생은 끝에서 정지하며 **반복**을 켜면 처음으로 돌아갑니다.

## 원자 추적과 원자 수 변화

첫 구조가 전체 원자 번호를 정의합니다. 다음 구조는 **원소 순서를 유지하는 공통 부분열**로 자동 대응하며, 대응하지 않는 원자는 새 번호를 받습니다. 따라서 공통 원자 순서가 같은 파일이나 중간에 조각이 삽입·제거된 파일을 연결할 수 있습니다. 같은 원소끼리의 교환이나 재번호 매김을 화학적으로 증명하는 알고리즘은 아닙니다.

표의 **대응 결과**에서 공통·추가·이탈 개수를 확인하세요. 두 번째 이후 단계를 선택하고 **원자 대응…**에서 파일의 각 원자를 기존 전체 번호에 연결할 수 있습니다. 0은 새 원자입니다. 중복 번호와 원소 불일치는 허용하지 않습니다. 이전 단계에서 빠졌다가 다시 들어오는 조각도 수동으로 기존 번호에 연결할 수 있습니다. 단계 순서 변경·제거는 번호를 다시 계산하므로 수동 대응과 강조·수동 조각 이동을 초기화합니다. 한 단계의 수동 대응 수정은 이후 단계의 수동 대응을 초기화합니다.

등장 전의 원자는 화면 위에서 보이지 않는 상태로 준비되어 내려오고, 이탈 원자는 위로 이동합니다. **이탈 조각을 위에 반투명하게 남기기**를 켜면 이후 단계에서도 불투명도 18%로 남습니다. 이동은 조각 전체에 같은 평행이동을 적용하며 내부 결합을 유지합니다. 이탈 조각과 반응 중심 사이의 결합은 남기지 않습니다. 위치를 벗어날 때는 전체 경로 맞춤을 사용하세요.

파일에 계속 포함되는 OTf·용매 등은 해당 조각 전체를 선택하고 **선택 조각 위로 이동**을 누르세요. 현재 시점부터 1.2초 동안 위로 이동하면서 반투명해지고 반응 중심과의 연결 결합은 사라집니다. 이는 발표를 위한 표시 연출입니다. **조각 이동 복원**으로 되돌립니다. 조각 이름이나 화학종으로 OTf를 자동 판단하지 않습니다.

## 강조와 저장

Shift/Ctrl 또는 빈 곳 드래그로 원자를 선택한 뒤 **선택만 표시 / 나머지 반투명 / 전체 복원**을 사용합니다. 강조 설정은 전체 번호를 따라 모든 단계에 적용됩니다. **원자 번호**는 원자 대응 검토에 유용합니다. 일반 창에서 가져온 구조의 원자 숨김·불투명도도 초기 설정으로 유지합니다.

**프로젝트 저장…**은 구조·경로 좌표를 포함한 `.ycmechanism` 파일을 만듭니다. 원본 계산 파일을 다시 읽지 않아도 단계 순서, 시간, 대응, 강조, 조각 이동, 카메라를 복원할 수 있습니다.

- **GIF**: 추가 프로그램 없이 저장합니다. 프레임을 하나씩 렌더링·인코딩하여 전체 영상 비트맵을 메모리에 쌓지 않습니다. 원자 반투명 효과를 유지하기 위해 현재 배경색에 합성합니다.
- **MP4**: ffmpeg가 PATH에 있으면 사용할 수 있습니다. PNG 임시 프레임에서 H.264 영상으로 변환합니다.
- **PNG 시퀀스**: 지정 폴더 아래 새 `Youngcraft-Mechanism-…` 폴더에 같은 크기의 프레임과 `timeline.json`을 저장합니다. **PNG 투명 배경**으로 실제 부분 알파를 유지할 수 있습니다. 취소하면 완료된 PNG만 해당 폴더에 남습니다.

GIF와 MP4는 저장 성공 후 결과 파일을 교체합니다. 취소·실패 시 기존 영상을 유지합니다. 영상의 각 프레임은 동일한 카메라와 캔버스를 사용하며 개별 프레임에 맞춘 자동 잘라내기를 하지 않습니다. 단계 이름은 영상에 넣거나 끌 수 있습니다. 한 번에 최대 18,000프레임, 단계당 2,000원자, 300단계, 전체 노드×원자 트랙 2,000,000까지 지원합니다.

## 해석 범위

입력 구조와 제공된 경로 프레임은 보존하고 사이 구간을 속도가 연속적인 3차 보간으로 연결합니다. 공통 결합의 길이를 보정하지만 힘장·반응 장벽·시간척도를 계산하지 않습니다. 따라서 실제 분자동역학·검증된 최소 에너지 반응 경로를 새로 계산하는 기능은 아닙니다. 계산 경로가 없는 구간의 원자 경로·충돌·수소 이동은 발표 전에 확인해야 합니다. 원자 수 변화는 원자 삭제나 자동 반응식 추론을 의미하지 않습니다.

## 검증

`test_mechanism`은 끝점 보존, 연속 속도, 강체 정렬, 다른 원자 수·조각 등장/이탈, 수동 대응 검증, 역방향 경로, 결합 길이·결합 페이드, 조각 평행이동, 프로젝트 왕복, GIF 스트리밍·취소 시 기존 파일 보존을 확인합니다. GUI smoke test는 실제 OpenGL에서 재생·카메라 유지·강조 유지·프로젝트 복원·GIF/PNG 내보내기를 확인합니다.

사용자가 지정한 Deformylation의 5개 파일은 별도 환경 변수 기반 테스트로 읽습니다. 경로는 `…ircrev-opt-freq.out` → 첫 TS → `…ircfwd-opt-freq.out` → AfterCC/OO cleavage TS → 해당 forward 최적화 구조 순서입니다. 이는 사용자가 지정한 구간이며 전체 Deformylation 반응의 최종 생성물이라고 단정하지 않습니다.

# 리간드 금속 배위와 연속 그리기

## Lab Ligands

**구조 만들기 → Lab Ligands · 연구용 리간드…** 또는 그리기 도구의 **Lab Ligands…**를 엽니다.

- 분류 목록 상단에 `Lab Ligands · 연구용 리간드`와 `Lab Oxygen · 산소 배위 조각`을 별도로 배치했습니다. 일반 리간드/작용기 목록에서도 같은 분류로 필터링할 수 있습니다.
- Lab Ligands 전용 화면은 기본적으로 **선택한 금속과 배위한 구조를 새 탭에 생성** 모드로 열립니다.
- 리간드, 금속, 금속 형식 전하, 전체 구조 총전하, multiplicity를 선택하면 실제 생성할 배위 구조를 미리 보여줍니다. 생성 시 주개 원자를 금속에 배위 결합으로 연결하고 dummy 원자를 제외합니다.
- 기본 multiplicity 제안은 전자 수의 홀짝만 맞춥니다. 실제 spin state를 계산하거나 결정하지 않습니다. 전하와 multiplicity는 직접 수정할 수 있습니다.
- **리간드 / 조각만 배치 또는 기존 금속에 연결** 모드를 고르면, 기존과 같이 화면에 배치하거나 이미 그린 금속/빈 배위 자리를 클릭해 연결할 수 있습니다.
- 새 금속을 선택해도 리간드 템플릿의 내부 구조와 기준 배위 거리를 유지합니다. 이는 시작 구조이며 금속별 평형 배위 구조를 계산한 결과는 아닙니다.

## 연속 결합

새 구조 그리기에서 **연속 결합**이 기본으로 켜집니다. 기본 결합 차수는 단일입니다.

1. 빈 곳을 클릭해 첫 원자를 놓습니다.
2. 다음 위치로 포인터를 옮기면 결합 미리보기가 나옵니다. 클릭할 때마다 사슬이 이어집니다.
3. 기존 원자를 클릭하면 그 원자에 연결해 고리를 닫을 수 있습니다. 분기하려면 `Esc`로 현재 사슬을 끝내고 분기점 원자를 선택한 뒤 이어 그립니다.
4. 빈 곳에서 드래그하면 원자 두 개와 결합을 한 번에 만듭니다. 기존 원자에서 드래그하는 동작도 유지합니다.
5. 화면 평면에서 30° 방향과 원소/결합 차수에 따른 길이를 스냅합니다. `Alt`를 누르면 방향·길이 스냅을 해제합니다. 기존 원자에 대한 연결 스냅은 유지합니다.
6. `Esc`, **새 사슬 (Esc)** 또는 우클릭으로 현재 사슬을 끝냅니다. 사슬을 끝낸 상태의 우클릭은 기존 원자/결합 삭제 동작입니다.

**연속 결합**을 끄면 독립 원자 배치 방식으로 돌아갑니다. 원소 버튼·키보드 원소 입력, `1`/`2`/`3` 결합 차수, 자동 수소 보정과 함께 사용할 수 있습니다. 결합/사슬을 확정할 때마다 실행 취소가 가능하며, 빈 곳에서 시작한 드래그 결합은 한 번에 취소합니다. 취소·재실행·구조 교체 시 이전 사슬 기준점을 지워 다른 원자로 잘못 연결되는 것을 방지합니다.

이 기능은 3D 뷰의 현재 화면 평면에서 골격을 빠르게 만드는 도구입니다. 고리 닫기는 연결을 추가하며 전체 고리 좌표를 자동 최적화하지 않습니다. 완성한 시작 구조는 기존 MM/xTB 기능으로 정리할 수 있습니다.

## 검증

- 모델 검사: 연구용 리간드 5종 × 금속 Mn/Fe/Co/Ni/Cu 조합, 배위 결합 수, 실원자 수, 총전하와 multiplicity 전달, 잘못된 금속 입력 시 원본 보존.
- Windows GUI 검사: Lab Ligands 필터, MDAP 선택, Co 금속 변경, 실제 미리보기와 생성 결과 비교.
- Windows 입력 검사: 연속 클릭, 방향/길이 스냅, 기존 원자에 고리 닫기, Esc, 드래그 시작의 단일 실행 취소, 자동 수소 재인덱싱 후 사슬 연장.
- `lab-ligands-cobalt.png`와 `continuous-drawing.png`는 실제 Qt/OpenGL 화면 캡처입니다.
- Release 빌드와 CTest 7개 묶음이 모두 통과했습니다. 추가한 Windows GUI 입력 검사 두 항목도 통과했습니다. 실제 생성 구조는 Co–MDAP 41원자/주개 4개와 사용자가 지정한 총전하·multiplicity로 확인했습니다.

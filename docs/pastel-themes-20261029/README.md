# Pastel palette studies

Theme 드롭다운을 여섯 개의 색상 버튼으로 바꿨습니다. 각 버튼의 큰 원은 파스텔 색, 작은 밝은 원은 표면색, 작은 어두운 점은 잉크색을 미리 보여줍니다. 선택 테두리와 키보드 포커스, 이름과 분위기를 설명하는 툴팁을 제공합니다. 선택은 다음 실행에도 유지됩니다.

| 템플릿 | 종이 | 표면 | 파스텔 | 잉크 | 분위기 |
| --- | --- | --- | --- | --- | --- |
| 구름 소다 | #edf4fa | #fbfdff | #c5dfee | #446781 | 맑은 소다빛 |
| 세이지 온실 | #eef4ee | #fcfdf8 | #cbdcc6 | #4d6c5b | 식물 표본실 |
| 라일락 노트 | #f2eef8 | #fefcff | #dbceec | #6d5b85 | 보랏빛 안개 |
| 오트밀 아틀리에 | #f6f1e7 | #fffdf7 | #e6d8bb | #79634c | 종이와 모카 |
| 로즈 밀크 | #f8eef0 | #fffcfc | #edced7 | #865e6d | 장미와 도자기 |
| 살구 다실 | #faf0e8 | #fffdf9 | #f0d2b8 | #865f49 | 햇살과 크림 |

배경은 저채도 종이색, 입력 영역은 거의 흰 표면색, 경계선은 부드러운 중간색으로 구성합니다. 아이콘과 선택 상태는 짙은 잉크색으로 맞춰 가독성을 확보합니다. 분자 원소색과 출력 배경 설정은 유지합니다.

실제 Windows/OpenGL 화면에서 여섯 팔레트를 각각 클릭해 검사하고 `theme-0.png`부터 `theme-5.png`로 기록합니다. 검증 로그는 `test-results.txt`입니다.

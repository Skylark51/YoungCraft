# 시작 스플래시 — 2026-11-01

첫 실행 시 기존 Youngcraft 로고, 이름, 버전과 준비 안내를 표시합니다. 저장된 여섯 색상과 패턴 설정을 반영하며 고해상도 화면에서도 선명하게 그립니다.

스플래시 타이틀은 `YoungCraft`로 표기합니다. Georgia 세리프 서체에서 Young은 이탤릭, Craft는 정자로 조합하고 테마 색상을 반영한 그라데이션과 가는 곡선 장식을 사용합니다.

타이틀 아래에는 `Molecules Rendering, Orbital Analysis, Capture Tools`를 한 줄로 표시합니다.

스플래시는 메인 창 준비 전에 먼저 그립니다. 메인 창을 숨긴 채 최소 표시 시간 3초(3000ms)를 채우고 180ms 동안 페이드아웃한 뒤 메인 창을 표시합니다. UI 스레드를 sleep으로 멈추지 않으며 클릭해도 표시 시간을 건너뛰지 않습니다. 준비 중 들어온 파일 열기 요청도 메인 창 표시 후 처리합니다. 종료할 메인 창이 사라진 경우에도 안전하게 숨깁니다.

기존 실행 프로세스에 파일을 전달할 때에는 스플래시를 만들지 않습니다. 시작 화면을 그리는 동안 들어온 파일 열기 요청은 대기시킨 뒤 메인 창 준비 후 전달합니다. 원격 서버 연결을 기다리지 않고 작업 공간을 표시합니다.

검증: `startupSplashShowsAndCloses`에서 로고 리소스, 표시, 자동 닫힘, 메인 창 유지, 준비 도중 메인 창 삭제를 검사합니다. `mainWindowStartsWithKoreanUi`와 기존 단일 인스턴스 동시 실행·한글 경로 전달 테스트도 실행합니다. Windows GUI 테스트 결과는 `workflow-test.txt`, 단일 인스턴스 결과는 `instance-test.txt`, 화면은 `preview.png`에 있습니다.

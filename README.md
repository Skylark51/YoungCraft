# Youngcraft

## 연구 프로젝트 라이브러리 / Reaction Pathway

상단 도구 모음의 **프로젝트** 아이콘(단축키 **Ctrl+Shift+P**)에서 연구 프로젝트를 등록하고 Gaussian 출력 파일을 반응 단계별로 정리할 수 있습니다. 시작할 때 자동으로 열리지 않습니다. Reactant/TS/Intermediate/Product의 순서를 조절하고, 기준점과 전자 에너지 또는 Gibbs 에너지를 선택해 상대 에너지 프로파일과 SI용 CSV를 생성합니다. 프로젝트는 별도의 `.ycproject` 파일에 저장됩니다. [사용 안내](docs/PROJECT_LIBRARY.md).

Gaussian 결과를 빠르게 탐색하는 Windows x64용 경량 분자구조 뷰어/계산화학 분석기입니다.

- **거리·각도·이면각 편집**: 보기 상태에서 원자를 순서대로 2/3/4개 클릭하면 하단 편집 막대가 나타납니다. 값을 입력하고 **적용** 또는 Enter를 누르세요. **→ 끝 원자 쪽 / ← 첫 원자 쪽 / ↔ 양쪽 이동**을 선택할 수 있으며 연결된 조각은 함께 움직입니다. **표시** 버튼은 측정 라벨을 켜고 끕니다. 계산 파일은 적용 시 현재 프레임의 편집 복사본을 새 탭에 만들며, Ctrl+Z/Ctrl+Y로 취소·재실행합니다. 분리할 수 없는 고리 구조는 변경하지 않습니다.

- **맞춤 캡처 (IRC · TS · IRC)**: `-freq-ts-freq.out`을 열면 같은 폴더의 forward/reverse IRC 최종 구조와 TS 애니메이션을 자동으로 미리 봅니다. 회전 동기화·좌우 교환·투명 배경·같은 높이·Word 각 5 cm / PowerPoint 각 10 cm 복사와 개별 저장을 지원합니다. [사용법과 검증](docs/reaction-capture-20261025/README.md).

- Gaussian `.out` / `.log` / `.gjf` / `.com`: 구조, 최적화 프레임, SCF energy, force/convergence 값, frequency·허수 진동·normal mode, Mulliken charge/spin, dipole, TD-DFT 상태·전이, MO energy, NBO 자연전하·점유수·E(2)·Wiberg 분석, PCM 존재 여부
- `.xyz` / multi-XYZ trajectory
- `.cube`: 원자와 volumetric grid 읽기
- **Orbitals**: `.chk` → `.fchk` 변환, α/β FMO 등가면 및 MEP 생성(formchk/cubegen 연동), isovalue·위상색·불투명도·MEP 색상 범위 조절, NBO/Wiberg 표 분석과 TSV 저장. [사용법과 검증](docs/orbitals/README.md).
- `.fchk` / `.fch`: 구조와 α/β MO energy/occupation 읽기. 기존 단일 MO/density/potential cube도 사용 가능합니다.
- 구조 파일 `.cif` / `.mmcif` / `.cmf`, `.mol` / `.sdf` / `.sd` / `.mdl`, `.mol2`, `.pdb` / `.ent`, `.res` / `.ins`, `.cssr` 열기. CIF는 비대칭 단위·단위격자·2×2×2 Packing과 격자선 표시를 지원합니다.
- Youngcraft Studio 기본 스타일, 원소별 색상·크기와 결합·조명 설정의 즉시 미리보기
- ball-and-stick / stick / CPK / space-filling, 카메라 회전·zoom·pan·picking·라벨, PNG/JPEG/clipboard, GIF 및 ffmpeg가 설치된 경우 MP4
- 편집 > 새 구조 그리기: 원소와 결합 차수를 선택해 원자를 배치하고, 기존 원자에서 드래그하며 결합을 미리 볼 수 있습니다. Alt를 누르면 기본 결합 길이 스냅이 해제됩니다. `Ctrl+D`는 원자 이동 모드입니다.
- **연속 결합**: 클릭으로 사슬 연장, 기존 원자에 연결해 고리 닫기, 빈 곳에서 드래그해 결합 시작을 지원합니다. 30° 방향과 결합 길이를 스냅하며 `Alt`로 자유 배치, `Esc`로 사슬을 끝냅니다. 독립 원자를 배치하려면 연속 결합을 끕니다.
- **구조 만들기 > Lab Ligands**: 연구용 리간드 전용 분류에서 금속·전하·multiplicity를 선택하고 배위 구조를 미리 본 뒤 새 탭에 생성합니다. [사용법과 검증](docs/ligand-chain-20261019/README.md).
- 도구 > Geometry optimization (`Ctrl+Alt+O`): Auto/MMFF94/MMFF94s/UFF를 선택하고 실제 좌표·에너지·gradient·그래프를 보며 일시정지·재개·중단할 수 있습니다. 시작 구조 복원도 지원합니다.

MM opt는 원자별 형식 전하를 MMFF/UFF에 전달하여 하전 구조도 계산합니다. 형식 전하 합과 총전하가 다르거나 MMFF/UFF가 지원하지 않는 금속·배위·결합 환경이면, 총전하와 입력한 constraint를 유지한 채 포함된 GFN-FF로 자동 전환합니다. 실제 사용 중인 방법은 계산 화면에 표시합니다. GFN-FF 전환 시 최대 cycles는 지원 범위인 10–5000으로 맞춥니다.

## 실험실 착물 조합

**구조 만들기 > 금속–리간드–산소 조합...**에서 금속, 리간드, 산소 fragment를 선택하고 **구조 만들기**를 누릅니다. 기본적으로 편집 가능한 새 구조 탭을 만들며, GFN-FF 실행을 체크한 경우 계산도 시작합니다. 계산 결과는 수렴한 경우에만 자동 적용하며 중단/실패/미수렴은 완료로 표시하지 않습니다.

현재 12-MTP(Me3-TPADP), 14-MTP, MDAP, Me2S-DPADP와 이름 확인이 필요한 TBDAP 후보를 제공합니다. Peroxo/superoxo/hydroperoxo의 end-on/side-on을 선택할 수 있습니다. MPDAP와 CHDAP는 기준 구조 수령 후 추가합니다. **리간드 / 작용기 삽입**에서 기본 리간드를 배치하거나 금속에 연결할 수 있고, **리간드 템플릿 저장**으로 사용자 구조를 재사용할 수 있습니다. 새 산소 fragment는 편집용 시작 모델이며 전자 상태나 최적화된 배치를 보장하지 않습니다.

초기 fragment는 사용자가 제공한 Mn(III)–12-MTP–peroxo Gaussian 구조에서 추출했습니다. Cyclohexanone은 제외합니다. MTP 주개 N 4개와 peroxo O 2개의 배위 연결을 유지하며, 기본값은 금속(III)/총전하 +1입니다. 총전하와 후속 양자계산용 multiplicity는 조합 화면에서 수정할 수 있습니다. GFN-FF 자체는 스핀 상태를 계산하지 않습니다.

조합 계산의 기본값은 참고 구조의 금속–주개 원자 거리와 O–O 거리를 유지하는 조화 restraint입니다. Fe로 금속을 바꾸어도 시작 거리는 Mn 참고 구조에서 가져오므로, 생성 결과는 DFT 시작 구조용 후보입니다. 자유 최적화가 필요하면 계산 화면에서 거리 유지 체크를 해제하고 다시 계산합니다.

실험실 fragment는 실행 파일 옆의 `lab_fragments/ligands`와 `lab_fragments/adducts`에 CJSON으로 저장합니다. 새 ligand는 같은 형식의 파일을 추가해 등록할 수 있습니다. 기준 금속은 원소 0의 dummy로 표현하고, dummy와 연결된 원자를 주개 원자로 지정합니다. 함께 조합할 fragment는 같은 기준 금속 좌표계를 사용해야 합니다. 원본 추출 기록과 검증 결과는 `docs/LAB_COMPLEXES.md`에 있습니다.

## 용량 최적화 배포 및 패치

Windows에서 `tools/package_portable.ps1`을 실행하면 xTB의 실행 데이터와 필수 라이선스만 포함한 `Youngcraft-portable.zip`을 생성합니다. 기본 fragment는 Qt 리소스에 이미 포함되므로 외부 복사본을 추가하지 않습니다. ZIP에는 파일별 SHA-256이 기록된 `package-manifest.json`이 포함됩니다.

`release/Youngcraft-Patch.exe`를 실행하면 기존 Youngcraft 설치 폴더를 자동으로 검색합니다. 패처 옆에 `Youngcraft-portable.zip`이 있으면 그 파일을 사용하고, 없으면 GitHub 최신 릴리스에서 다운로드합니다. Youngcraft를 종료한 상태에서 실행해야 하며, ZIP 해시 검증 후 적용하고 이전 배포의 중복 xTB 소스 아카이브와 기본 fragment 복사본, 구버전 실행 파일 백업을 정리합니다. 사용자 `lab_fragments`와 `youngcraft-server.json`은 보존합니다. 실패 시 이전 파일을 복구합니다.

현재 GitHub 저장소에는 최적화된 ZIP 릴리스가 없습니다. ZIP을 찾을 수 없으면 패처는 구버전 잔재 정리만 수행하며 실행 파일은 유지합니다. 프로그램 자체를 업데이트하려면 최적화된 ZIP을 EXE 옆에 두거나 GitHub Releases에 게시해야 합니다. 상세 내용은 [패치 및 검증](docs/PORTABLE_PATCHING.md)을 참고하세요.

## 빌드

Qt 6.4 이상, CMake 3.24 이상, Ninja, C++20 컴파일러가 필요합니다.

```powershell
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

Windows portable 배포물은 Release 빌드 후 아래 스크립트로 만듭니다. 이 스크립트는 PyInstaller `--onedir`로 RDKit/Python이 포함된 `mm_runtime/YoungcraftMM.exe`를 생성해 포함합니다. 배포본의 MM 기능에는 사용자 PC의 Python, RDKit, 인터넷이 필요하지 않습니다. 빌드 PC에는 `python -m pip install -r tools/requirements-mm.txt`가 필요합니다.

```powershell
powershell -ExecutionPolicy Bypass -File tools/package_portable.ps1
```

완성물은 `dist\Youngcraft.exe`, `dist\mm_runtime\YoungcraftMM.exe`와 루트의 `Youngcraft-portable.zip`입니다. 배포 폴더에서 `Youngcraft.exe`를 직접 실행하거나 ZIP을 원하는 폴더에 풀어 실행합니다.

구조 파일 파싱에 포함된 Gemmi와 PEGTL의 라이선스는 배포본의 `licenses` 폴더에 있습니다.

## 같은 원자 수의 뷰 동기화 (2026-10-22)

상단 **뷰 동기화**(또는 보기 메뉴)를 켜면 현재 탭을 기준으로 원자 수가 같은 모든 탭의 회전·확대율·화면 이동·원근/직교 설정을 맞춥니다. 이후 어느 탭에서 조절해도 같은 원자 수의 탭이 함께 따라갑니다. 좌표 중심이 다른 파일은 각 분자 중심을 기준으로 같은 위치에 표시하며, 분자 크기로 확대율을 다시 정규화하지 않아 같은 확대율로 캡처할 수 있습니다. 크기를 정확히 비교하려면 직교 보기를 사용합니다. 이후 여는 파일에도 적용됩니다. 원자 수가 다른 그룹은 독립적으로 동기화되며, 버튼을 다시 끄면 개별 조절로 돌아갑니다. 원자 좌표와 결합은 변경하지 않습니다.

## 복사 이미지·애니메이션 여백 (2026-10-22)

**이미지 복사**는 투명 픽셀을 기준으로 분자와 라벨에 딱 맞게 여백을 자동 제거합니다. 재생 중인 화면을 복사할 때에는 2%의 작은 여유를 둡니다. GIF·PNG 애니메이션은 투명 배경으로 내보내며 전체 프레임의 표시 영역을 합쳐 동일한 크기로 자르고 2%(최소 2px)의 여유를 남깁니다. 프레임마다 분자가 재정렬되거나 움직임이 잘리지 않습니다. JPG는 형식상 투명을 지원하지 않아 흰 배경으로 저장합니다.

## 수소 제거 (2026-10-22)

상단 **이미지 복사** 바로 옆의 **수소 제거**는 탄소에 결합된 수소와 해당 결합을 화면에서 숨깁니다. O–H, N–H 등 다른 원자에 결합된 수소는 유지합니다. **수소 제거 초기화**는 탄소에 결합된 수소를 다시 표시합니다. 두 기능 모두 회전·확대·이동, 현재 프레임/진동 좌표와 선택을 유지하며 원자·결합 데이터는 삭제하지 않습니다.

## 단축키

상단 도구 모음의 **원자 번호** 버튼을 누르면 모든 표시 원자의 구 중심에 번호를 표시합니다. 다시 누르면 숨깁니다. 번호는 좌표/원자 표와 동일하며, 구 크기에 맞춰 축소하고 밝은 글씨와 어두운 외곽선으로 표시합니다. **보기 > 원자/결합 라벨 > 원자 번호** 메뉴에서도 같은 기능을 사용할 수 있습니다. 숨긴 원자와 수소는 해당 표시 설정을 켜면 번호도 함께 나타납니다.

일반 보기에서 원자를 순서대로 클릭하면 뷰 아래에 **2개: 거리(Å), 3개: 각도(°), 4개: 이면각(°)**이 표시됩니다. 각도의 꼭짓점은 두 번째 원자, 이면각의 중심 결합은 두 번째–세 번째 원자입니다. 선택 번호와 기존 측정값도 함께 표시하며, 프레임/진동으로 좌표가 바뀌면 값을 갱신합니다. 선택한 원자를 다시 클릭하면 그 원자만 선택 취소되며 남은 클릭 순서에 따라 측정값을 다시 계산합니다. 취소한 원자를 다시 선택하면 순서의 마지막에 추가됩니다. 네 개 선택 뒤 새 원자를 클릭하면 다음 측정을 시작합니다. 빈 배경이나 **측정 초기화** 버튼으로 초기화합니다. 일직선 배치 등 계산할 수 없는 이면각은 ‘정의 불가’로 표시합니다. 측정은 계산 구조와 프레임을 수정하지 않으며 탭마다 선택을 유지합니다.

`Ctrl+O` 열기, `Ctrl+S` 그림 저장, `Ctrl+I` 이미지 복사, `Ctrl+B` 결합 편집 모드, `Ctrl+D` 원자 드래그 모드, `Enter` 최적 보기, `Space` 중앙 정렬, `Num5` 회전 중심 갱신, `P` 애니메이션 재생/일시정지, 좌우 화살표 프레임/진동 이동.

**이미지 복사**(메뉴·도구 모음·`Ctrl+I`)는 화면 배경색과 관계없이 투명 배경으로 복사합니다. 클립보드에는 알파 채널을 유지한 이미지와 PNG 형식을 함께 제공합니다.

큰 출력 파일은 worker thread에서 한 줄씩 읽습니다. Gaussian 출력만으로 grid를 계산할 수 없는 경우에는 `.fchk` 또는 `.cube`를 명시적으로 요구합니다.


## Chemcraft 대응 기능 업그레이드 (2026-10-16)

- **편집 > 선택 확장 / 선택 반전 / 선택 원자에 결합된 원자 전체 선택**: 실제 선택 집합을 변경합니다. 확장은 결합 이웃 한 단계, 전체 선택은 연결된 조각 전체입니다. 유연한 선택에서 수소·비수소·원소별 선택을 지원합니다.
- **편집 > 선택 조각 복사 / 분자 조각 붙여넣기** (`Ctrl+C`, `Ctrl+V`): 선택 원자와 내부 결합·배위 자리·완전한 haptic contact를 복사합니다. 붙여넣기는 현재 구조 옆에 배치하고 한 번의 실행 취소로 되돌립니다. 클립보드의 텍스트 표현은 XYZ이며, Youngcraft 간에는 전용 형식으로 결합 정보를 유지합니다.
- **도구 > 분자 조각 추출기**: 결합 및 haptic 연결을 따라 분리된 조각이나 현재 선택을 새 탭으로 추출합니다. 원본 구조는 유지됩니다. 부분 조각의 총전하는 형식 전하 합이며 스핀 다중도는 후속 계산에서 확인해야 합니다.
- **도구 > Z-matrix 생성**: 앞선 원자를 참조하는 거리·각도·이면각을 생성하고 미리보기·복사·저장을 지원합니다. 기존의 Cartesian 좌표 나열을 교체했습니다. 이면각을 정의할 수 없는 선형 기준 배치는 이유를 표시하며 Cartesian 입력을 사용해야 합니다.
- **도구 > 계산 입력파일 구역 생성**: 현재 화면 좌표로 Gaussian Cartesian 입력을 생성합니다. 경로·총전하·스핀 다중도를 수정하고 미리보기·복사·GJF 저장을 지원합니다. 추가 구역/체크포인트가 필요한 일부 경로는 거부합니다. 예시 계산 경로는 목적에 맞게 수정해야 합니다.

검증 및 비교 한계: `docs/chemcraft-tools-20261016/README.md`.

## 원자 표시와 분석 사이드바 (2026-10-16)

- **보기 > 특정 원자 숨기기**와 **숨긴 원자 모두 복원**은 회전·확대·이동, 현재 프레임/진동 좌표, 패널 선택과 스크롤을 유지합니다. 다중 선택과 결과 목록에서 고른 단일 원자 모두 지원합니다.
- 상단 두 번째 줄의 **Opt·Freq·Scan·IRC·TD-DFT·Atom Properties·Orbitals·XYZ**로 분석 내용을 선택합니다. 실제 내용은 좌측 사이드바에 표시합니다. 기본 폭은 320px, 최대 폭은 360px이며 같은 버튼을 다시 누르면 접거나 펼칩니다. 작은 영역에서는 스크롤로 전체 내용을 확인합니다.
- **보기 > 기본 패널 배치 복원**은 좌측 배치로 복원합니다. 문서별 분석 선택을 유지합니다.
- 구조 뷰는 작업 영역 전체를 채우며 창 비율에 맞춰 가로·세로로 자유롭게 늘어납니다. 화면의 정방형 제한과 비활성 여백은 없습니다. 캡처 크기는 화면 크기와 별도로 처리하며, 더 좁은 비율로 캡처할 때는 전체 가로 구도가 잘리지 않도록 투영 범위를 맞춥니다. 이미지 복사는 기존처럼 투명 배경의 내용 경계에 맞춰 자릅니다.
- Scan 곡선·포인트별 최적화 이력은 **Scan > 스캔 그래프...** 창에 통합합니다. 하단 프로파일은 표시하지 않습니다.
- 주 도구 모음은 **구조 그리기·MM opt·베스트뷰·가운데 배치·Atomic number·애니메이션**을 표시합니다. **애니메이션**은 Freq 선택 시 진동 재생/일시정지, 그 외에는 구조 프레임 재생/일시정지입니다. Atomic number 버튼은 기존 원자 번호 표시 기능입니다.

검증 기록: `docs/sidebar-square-20261016/`.

## 슈퍼샘플링 (2026-10-16)

안티앨리어싱을 켜면 3D 장면을 화면의 가로·세로 각각 2배 해상도로 렌더링하고, 네 픽셀을 평균해 화면으로 축소합니다. 원자 번호·측정값·격자선 등 문자/주석은 축소 후 원래 해상도로 표시합니다. 이미지 저장·복사에도 적용되며 투명 배경의 가장자리 색과 부분 투명도를 유지합니다.

스타일 편집기의 **슈퍼샘플링 (가로·세로 2배) + MSAA** 항목으로 켜고 끕니다. 기본 설정은 켜짐입니다. 렌더링 픽셀은 4배가 되므로 GPU 부하가 늘어납니다. GPU 크기 제한, 렌더 타깃 1,677만 픽셀 초과 또는 프레임버퍼 생성 실패 시 기존 MSAA 방식으로 돌아갑니다.

검증 및 비교 이미지: `docs/supersampling-20261016/`.

## 논문용 이미지 저장 (2026-10-21)

**Youngcraft Studio**는 Youngkly에서 맞춘 스타일로 교체했습니다. 흰 배경, 검정 탄소(RGB 12,12,12), 순수 파랑 질소·순수 빨강 산소, 파스텔 민트 F·Cl, 작은 원자와 반지름 0.032의 가는 결합을 사용합니다. 원근 왜곡 없는 카메라와 한 방향의 조명에 작은 반사점·넓은 광택을 함께 적용합니다. 이전에 저장한 Studio 설정은 revision 3으로 한 번 갱신하며, 갱신 이후 사용자가 수정한 설정은 그대로 저장·복원합니다. Youngkly도 이 프리셋을 직접 참조합니다.

**Dark Studio**는 Youngcraft Studio의 설정을 그대로 사용하고 배경만 순수 검정(RGB 0,0,0)으로 바꿉니다. 이전 Dark Studio 설정도 한 번 갱신합니다.

그림 저장은 화면 비트맵 확대 대신 지정한 픽셀 크기에서 분자 장면을 새로 렌더링합니다. 저장할 때 긴 변의 픽셀 수를 선택하며 기본값은 3000px입니다. PNG에는 600 dpi 정보와 sRGB 색 공간을 기록합니다. **이미지 복사**도 긴 변 3000px의 투명 PNG를 사용합니다. 픽셀 수가 실제 세부 묘사를 결정하며, dpi 정보는 인쇄 크기를 해석할 때 사용합니다. 예를 들어 너비 5cm에 600dpi로 인쇄하려면 잘라낸 그림 너비가 최소 약 1181px이어야 합니다.

출력용 프레임버퍼에서 MSAA를 적용하고 GPU 메모리·크기 제한 내에서 가로·세로 2배 슈퍼샘플링을 추가합니다. 구의 분할 수준도 화면이 아닌 실제 렌더링 픽셀 수로 선택합니다. 라벨·측정선·격자선은 출력용 캔버스에 직접 그리며, 저장 전후의 카메라·화면 크기·선택 상태는 유지합니다. 투명 가장자리의 색과 부분 투명도를 보존합니다. 애니메이션 저장도 선택한 프레임 해상도에서 직접 렌더링합니다. GIF는 256색 형식이므로 논문용 정지 그림은 PNG를 사용하세요.

검증 기록: [고해상도 저장 개선](docs/PUBLICATION_EXPORT_20261021.md).

## 여러 파일과 창 간 탭 이동 (2026-10-22)

WinSCP의 외부 프로그램 열기, 탐색기, 명령줄에서 Youngcraft를 여러 번 실행해도 현재 실행 중인 창에 문서 탭으로 추가합니다. 한 번에 여러 파일 경로를 전달할 수 있으며 한글·공백 경로를 지원합니다. 기존 창이 최소화되어 있으면 복원합니다.

별도 창이 필요하면 **파일 > 새 창** (`Ctrl+Shift+N`), **파일 > 현재 탭을 새 창으로 분리**, 또는 탭 오른쪽 클릭의 **이 탭을 새 창으로 분리**를 사용합니다. 명령줄의 `--new-window`도 같은 실행 프로세스 안에서 새 창을 만듭니다.

분리된 창을 합치려면 **문서 탭 제목을 위나 아래로 끌어 탭 줄 밖으로 꺼낸 뒤, 다른 Youngcraft 창의 탭 줄이나 본문에 놓습니다.** 탭 줄 안에서 좌우로 끌면 순서만 바뀝니다. 이동 후 편집 내용, 실행 취소/다시 실행, 원자 표시·선택, 카메라, 분석 패널과 애니메이션 상태를 유지합니다. 탭 이동 중 진행 중인 MM 최적화는 기존 탭 전환과 같이 중단합니다. 파일 분석 중인 탭은 분석 완료 후 이동할 수 있습니다. 마지막 탭을 옮긴 원래 창은 빈 창으로 남습니다.

이 기능은 업데이트된 실행 파일에서 연 창들 사이에 적용됩니다. 업데이트 전 버전의 창은 닫고 새 버전으로 파일을 다시 열어 사용하세요.

## 직접 구조 편집 · 부분 최적화 · 도구 안내 (2026-11-02)

원자 번호 표시 오른쪽 구분선 뒤에서 **원자 이동, Fragment 각도, Fragment 비틀림, 분자 이동/회전, 결합 각도**를 고릅니다. `Ctrl+A`로 현재 메인 화면에 표시된 모든 원자를 선택합니다(텍스트 입력칸에서는 일반 텍스트 선택 단축키로 동작). **분자 이동/회전**은 클릭한 원자와 결합으로 연결된 분자 한 개만 조작합니다. **Fragment 각도**는 클릭한 가지를 부착 원자 기준으로 기울이고, **Fragment 비틀림**은 메틸기(CH3)처럼 단일 비고리 결합으로 분리되는 가지를 결합축을 중심으로 회전합니다. 수소를 클릭해도 소속 가지를 선택합니다. 고리 결합 등 안전하게 분리할 수 없는 가지는 움직이지 않습니다. 선택 표시는 밝은 배경에서 파랑, 어두운 배경에서 청록 네온 테두리로 표시합니다. 결합 각도 도구에서는 결합을 클릭하고 끝점을 드래그합니다. Ctrl: 비틀림, 오른쪽 드래그: 거리, Alt: 반대편 조각. Ctrl+Z/Y로 편집을 취소/재실행합니다. 거리·각도·이면각의 숫자 입력은 기존 화면 아래 측정 편집기를 사용합니다.

부분 최적화는 **기존 구조를 연 뒤 구조 고정 → 새 원자/조각 추가 → MM opt 또는 QM opt** 순서입니다. 선택이 있으면 선택한 원자만, 선택이 없으면 현재 전체 구조를 고정합니다. 고정 원자는 작은 파란 사각형으로 표시하고, 추가 원자는 자유롭게 움직입니다. **고정 해제**도 선택/전체에 적용됩니다. 고정 목록은 문서와 편집 취소 이력에 유지하며, XYZ 좌표 파일에는 저장되지 않습니다. 고정한 기존 자동 수소도 새 조각을 추가할 때 재생성하지 않습니다.

MM/xTB 설정의 Constraint 표에서 고정 목록을 확인·수정할 수 있습니다. 거리 항목에 두 원자 번호와 목표 Å를 넣으면, 고정되지 않은 쪽을 먼저 그 거리로 배치하고 거리 restraint를 포함해 최적화합니다. 시작 거리 배치는 고정 좌표와 조각 내부 구조를 보존할 수 있을 때만 진행합니다. 최종 거리는 조화 restraint의 허용 오차가 있으며, 고정 원자의 Cartesian 좌표는 유지합니다. 전체 원자 고정, 서로 충돌하는 시작 거리, 양쪽 모두 고정된 원자의 거리 변경은 안내 후 실행하지 않습니다. MMFF94/MMFF94s/UFF와 GFN-FF 자동 전환 모두 고정 목록을 유지합니다. 고정 xTB 계산은 동봉 gfnff/xtb.exe의 GFN1/GFN2/GFN-FF 기능을 사용하고 출력 좌표의 고정 준수도 검사합니다.

Opt 패널의 **최적화 그래프…**는 별도 창으로 열립니다. 점 클릭과 프레임 선택·슬라이더·재생이 서로 연결되며, 패널 내부 그래프는 제거했습니다. Scan 그래프는 기존 동작을 유지합니다.

빈 공간을 우클릭하면 원자·결합·측정 선택을 해제합니다. 오른쪽 드래그는 계속 시점을 회전합니다. 그리기 모드 진입 후에는 원소 또는 **원자 / 결합 그리기**를 명시적으로 선택해야 그려집니다. 원소를 이미 C로 표시하고 있어도 C 버튼을 누르면 선택됩니다.

진동 애니메이션을 선택하면 분자 화면 아래에 **진동 일시정지/재개**, **원래 구조**가 나타납니다. 패널을 닫아도 조작할 수 있으며 일시정지 뒤 같은 위상에서 재개합니다. 상단 MM opt 바로 옆 **QM opt**로 xTB 계산 설정을 엽니다. 상단 도구에는 좌측 상단 기능명(OPT/FREQ/SCAN/IRC/TD-DFT 등), 우측 하단 실제 단축키를 표시합니다. Ctrl+N은 새 구조입니다. 기존 Ctrl+O, Ctrl+I, Ctrl+Alt+I, Ctrl+Alt+O, Ctrl+D도 해당 아이콘에 표시합니다.
